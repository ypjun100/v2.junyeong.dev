(주)구름 풀스택 엔지니어
2024.09 — 재직 중

개발자 채용·평가 플랫폼 Devth의 풀스택 개발을 담당하고 있습니다. Electron 설치형 응시 앱, AI 부정행위 탐지, CSAP 인증처럼 프론트엔드·백엔드·인프라를 아우르는 과제를 설계하고 실제 시험 환경에 적용했습니다.

Electron 설치형 응시 앱 신규 구축
  • 신규 레포의 아키텍처 설계부터 Electron 앱 핵심 기능 구현과 릴리즈 구축까지 주도
  • AI 프로세스 탐지, 다중 모니터 탐지 등을 독립 모듈로 분리해 추가/변경이 쉬운 구조로 설계
  • Windows/macOS 코드 서명 및 공증, AWS S3 기반 앱 자동 업데이트 기능 구현
  • 개발 시작 한 달 만에 1,500명 규모 시험에 적용해 부정행위 의심 사례 80건 자동 탐지
AI 부정행위 탐지 시스템
  • AI 모델 자체를 제외한 백엔드·인프라·서비스 연동 구조를 주도적으로 설계·구현
  • Kakao KiC GPU 서버와 AWS MSK의 연결 제약을 Proxy Pod 브리지 구조로 해결하고 SRE와 인프라 구성
  • 기존 10초 주기 웹캠 캡처 이미지를 활용하는 구조로 전환해 AWS Chime 영상 처리 비용 제거
CSAP SaaS 표준등급 인증 대응
  • MongoDB View와 JavaScript Proxy를 결합해 대규모 비즈니스 로직 수정 없이 권한별 계정 컬렉션 분리 요건 충족
  • Devth·goormEDU 25개 이상 페이지에 이름·이메일 등 개인정보 마스킹 적용
  • 여러 컨설팅 업체 및 내부 부서와 인증 요건을 논의하고, 인증 대응 개발 작업 전반을 전담
