# 스펙 — 포트폴리오 겸 블로그 사이트 v2

## 배경

윤준영의 온라인 존재는 지금 두 곳으로 나뉘어 있다. 포트폴리오(프로젝트·수상 경력)는 `junyeong.dev`에, 기술 블로그는 `blog.junyeong.dev`에 있다. 두 사이트는 서로 다른 테마와 톤을 쓰고 있어 한 사람의 결과물로 읽히지 않는다.

v2는 이 둘을 하나의 사이트로 합치고, Claude Design에서 확정한 다크 미니멀 시안을 그대로 입힌다. 글 본문은 전부 저장소 안의 마크다운 파일에서 읽어 온다.

## 사용자와 필요

### 사이트 방문자

- 첫 화면에서 이 사람이 누구이고 지금 무엇을 하는지 5초 안에 파악한다.
- 최근에 쓴 글 몇 편을 첫 화면에서 바로 훑고, 관심이 가면 전체 목록으로 넘어간다.
- 이 사람이 만든 프로젝트와 받은 상을 한 페이지에서 훑고, 궁금한 항목을 눌러 상세 내용을 읽는다.
- 블로그 글 전체를 연도별로 훑어 원하는 글을 찾는다.
- 글 상세 화면에서 본문·코드 블록·이미지를 편안하게 읽는다.
- 모바일에서도 위 모든 동작이 데스크톱과 동일하게 가능하다.

### 사이트 운영자(저자)

- 새 글을 쓸 때 정해진 폴더에 마크다운 파일 하나만 추가하면 목록과 상세 페이지에 자동으로 반영된다. HTML을 건드리지 않는다.
- 소개 문구, 기술 스택, 활동 이력은 사이트 전체에서 한 곳에만 적혀 있어, 고칠 곳을 찾아 헤매거나 같은 내용을 두 번 고치지 않는다.
- 로컬에서 사이트를 띄워 결과를 확인한 뒤 푸시하면 자동으로 배포된다.

### 이 저장소에서 작업하는 에이전트

- 저장소를 처음 여는 시점에 빌드/실행 명령, 디렉터리 역할, 글 작성 규칙, 검증 절차를 문서 하나로 파악한다.

## 화면

사이트는 네 가지 화면으로 이루어진다.

1. **Home** — 대표 문구, 요약 지표 3개, 자기소개 문단, 최근 글 5편.
2. **About** — Home과 동일한 소개 블록에 더해 기술 스택, 프로젝트 전체 목록, 수상 경력 전체 목록, 활동 이력.
3. **Posts** — 블로그 글 전체 목록. 연도별로 묶고 각 항목은 날짜와 제목으로 표시한다.
4. **Post** — 글 상세. 블로그 글, 프로젝트, 수상 경력이 모두 이 화면 형태를 공유한다.

좌측에는 모든 화면에서 동일하게 보이는 프로필 영역이 있다. 아바타, 이름, 직함, 화면 이동 링크, 외부 링크(GitHub·LinkedIn·이메일)로 구성된다.

## 콘텐츠 요구사항

- 블로그, 프로젝트, 수상 경력은 각각 별도의 폴더에 마크다운 파일로 존재한다. 폴더에 있는 항목이 곧 페이지에 나오는 목록이다. 하드코딩된 목록은 어디에도 없다.
- 기존 두 사이트의 글을 모두 옮겨 온다. 블로그 21편, 프로젝트 10편, 수상 경력 6편이며 각 글이 참조하는 이미지도 함께 옮긴다.
- 프로젝트와 수상 경력 상세 화면은 기존 글이 갖고 있던 부가 정보 — 사용 기술, 이미지 모음, 참여자 구성, 외부 링크, 수상 등급 — 를 계속 보여준다. 표현은 새 시안의 다크 미니멀 톤으로 다시 만든다.
- 기존 두 사이트의 글 주소를 그대로 유지해 외부에 걸린 링크가 깨지지 않는다.

## 디자인 요구사항

- Claude Design 시안의 색, 타이포그래피, 간격, 여백을 그대로 재현한다.
- 시안에 없는 화면 폭에 대한 대응은 시안의 조형 원칙을 지키면서 직접 설계한다. 좁은 화면에서 좌측 프로필 영역과 본문이 겹치거나 잘리지 않고, 가로 스크롤이 생기지 않는다.
- 코드 블록은 좁은 화면에서 가로 스크롤로 처리하며 페이지 전체 레이아웃을 밀어내지 않는다.

## 배포 요구사항

- `v2.junyeong.dev`에서 접속된다.
- 기본 브랜치에 푸시하면 자동으로 빌드·배포된다.

## 성공 기준

- 네 화면이 모두 동작하고, 각 화면이 시안과 시각적으로 일치한다.
- 세 콘텐츠 폴더의 파일 개수와 사이트에 표시되는 목록 항목 개수가 정확히 일치한다.
- 목록의 모든 항목을 눌러 상세 화면으로 이동할 수 있고, 이동한 화면에 본문이 정상 렌더링된다.
- 기존 사이트의 프로젝트·수상 경력·블로그 글 주소가 v2에서도 동일하게 열린다.
- 사이트 빌드가 경고 없이 성공하고, 내부 링크와 이미지 참조 중 깨진 것이 없다.
- 375px, 768px, 1280px 폭에서 레이아웃이 깨지지 않고 가로 스크롤이 발생하지 않는다.
- 저장소 루트의 에이전트 안내 문서만 읽고도 빌드·실행·글 추가·검증을 수행할 수 있다.

## 범위 밖

- 검색, 댓글, 조회수, 다크/라이트 테마 전환.
- 기존 두 사이트의 저장소 정리 및 종료. v2는 새 저장소에서 독립적으로 만들고, 기존 사이트는 그대로 둔다.
